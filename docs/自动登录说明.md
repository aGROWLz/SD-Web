# 🔧 自动登录配置说明

## 配置效果

项目已配置为**开发模式自动登录**，访问登录页面时自动以管理员身份登录并跳转到功能界面。

## ✅ 工作原理

### 自动登录流程

```
访问任意页面
    ↓
未登录？ → 跳转到 /login
    ↓
检测到登录页面 + 开发模式
    ↓
自动登录管理员账号
    ↓
登录成功 → 跳转到 /create
```

### 核心代码

**位置：** [client/src/router/index.ts](file:///d:/Project/SD-Web/client/src/router/index.ts#L74-L85)

```typescript
// 🔧 开发模式：自动登录管理员账号
const DEV_MODE = import.meta.env.DEV

if (DEV_MODE && !authStore.isAuthenticated() && to.path === '/login') {
  // 在登录页面时自动登录管理员账号
  try {
    await authStore.login('admin@seedance.com', 'admin123456')
    console.log('🔧 开发模式：已自动登录管理员账号')
    next('/create') // 登录成功后跳转到创作页面
    return
  } catch (error) {
    console.error('⚠️ 自动登录失败，请检查后端服务:', error)
    // 登录失败，显示登录页面让用户手动登录
  }
}
```

## 🐛 故障排查

### 问题：无限重定向到登录页

**症状：** 页面不断刷新，在 `/login` 和 `/create` 之间跳转

**原因：** 自动登录失败或后端未启动

**解决：**
1. 检查后端服务是否运行：`http://localhost:3000/health`
2. 查看控制台错误信息
3. 确认管理员账号已创建
4. 尝试清除浏览器缓存并刷新

### 问题：自动登录但跳转到 404

**症状：** 登录成功但页面显示 404

**原因：** 路由配置错误或组件加载失败

**解决：**
1. 检查路由配置是否正确
2. 确认 `/create` 路由存在
3. 查看控制台是否有组件加载错误

### 问题：无法访问管理员功能

**症状：** 点击"用户管理"等菜单跳转回创作页面

**原因：** 自动登录成功但角色不是管理员

**解决：**
1. 检查用户角色：
   ```javascript
   console.log(JSON.parse(localStorage.getItem('user')))
   // 应该显示 role: "ADMIN"
   ```
2. 如果角色不对，重新运行更新管理员脚本：
   ```bash
   cd server
   npx ts-node src/scripts/update-admin.ts
   ```

### 问题：登录后token无效

**症状：** API 请求返回 401 未授权

**原因：** Token 过期或无效

**解决：**
1. 清除本地存储并重新登录：
   ```javascript
   localStorage.clear()
   location.reload()
   ```
2. 检查后端 JWT 配置
