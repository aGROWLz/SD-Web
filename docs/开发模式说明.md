## 🔄 切换回生产模式

当需要恢复登录功能时，按以下步骤操作：

### 1. 恢复登录路由

编辑 `client/src/router/index.ts`，取消注释：

```typescript
{
  path: '/login',
  name: 'Login',
  component: () => import('@/views/Login.vue'),
  meta: { requiresGuest: true }
},
{
  path: '/register',
  name: 'Register',
  component: () => import('@/views/Register.vue'),
  meta: { requiresGuest: true }
}
```

### 2. 恢复路由守卫

移除或注释掉自动登录逻辑：

```typescript
// 注释掉这部分
// if (DEV_MODE && !authStore.isAuthenticated()) {
//   await authStore.login('admin@seedance.com', 'admin123456')
// }

// 注释掉跳过认证
// if (DEV_MODE) {
//   next()
//   return
// }
```

### 3. 恢复用户菜单

编辑 `client/src/layouts/DefaultLayout.vue`：

```vue
<!-- 将 v-if="false" 改为 v-if="true" 或直接删除 -->
<div class="user-menu">
  <!-- 恢复原来的用户菜单代码 -->
</div>
```

```bash
cd client
npm run build
```

## 🐛 故障排查

### 问题：页面仍显示登录界面

**原因：** 自动登录失败或后端未启动

**解决：**
1. 检查后端服务是否运行
2. 查看控制台错误信息
3. 确认管理员账号已创建

### 问题：无法访问管理员功能

**原因：** 自动登录未成功或权限不足

**解决：**
1. 刷新页面重新自动登录
2. 检查控制台是否显示 "🔧 开发模式：已自动登录管理员账号"
3. 验证用户角色：
   ```javascript
   console.log(JSON.parse(localStorage.getItem('user')).role)
   // 应该显示 "ADMIN"
   ```

### 问题：修改代码后不生效

**原因：** 热重载未触发或浏览器缓存

**解决：**
1. 硬刷新页面：`Ctrl + Shift + R`
2. 清除浏览器缓存：`F12 → Application → Clear storage`
3. 重启开发服务器
