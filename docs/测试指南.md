# 测试指南

## 🐛 问题修复说明

### 问题 1：刷新后管理员账号变成普通账号
**原因**: 页面刷新后，`localStorage` 中只保存了 token，但没有保存用户信息（包括角色），导致 `authStore.user` 为 null，`isAdmin()` 判断失败。

**修复方案**: 
- 在登录时同时保存 token 和用户信息到 `localStorage`
- 页面加载时从 `localStorage` 恢复用户信息
- 修改文件：`client/src/stores/auth.ts`

### 问题 2：左侧菜单点击后右侧没有内容
**原因**: `DefaultLayout.vue` 使用了 `<slot />` 而不是 `<router-view />`，导致子路由无法正确渲染。

**修复方案**:
- 将 `<slot />` 改为 `<router-view />`
- 修改文件：`client/src/layouts/DefaultLayout.vue`

## 📋 常见问题排查

### Q: 登录后立即被踢出
A: 检查 JWT token 是否过期，或者后端 JWT_SECRET 是否配置正确

### Q: API 请求失败（401 Unauthorized）
A: 
1. 清除 localStorage
2. 重新登录
3. 检查后端日志

### Q: 页面一片空白
A: 
1. 打开浏览器控制台查看错误
2. 确认前端服务正在运行
3. 确认后端服务正在运行

### Q: WebSocket 连接失败
A:
1. 确认后端服务启动时显示 "WebSocket server initialized"
2. 检查浏览器网络面板的 WS 连接
3. 确认 CORS 配置正确
