# 开发配置说明

## 🔧 开发模式配置

为了方便开发，已经配置了以下开发特性：

### 1. 自动登录管理员账号

在开发模式下（`npm run dev`），前端会自动登录管理员账号，无需手动输入：

```typescript
// 📍 位置: client/src/router/index.ts

// 开发模式下自动登录
const DEV_MODE = import.meta.env.DEV
if (DEV_MODE && !authStore.isAuthenticated()) {
  await authStore.login('admin@seedance.com', 'admin123456')
}
```

**效果：**
- ✅ 刷新页面自动登录
- ✅ 直接进入功能界面（创作页面）
- ✅ 控制台会显示 "🔧 开发模式：已自动登录管理员账号"

### 2. 管理员账号信息

```
📧 邮箱: admin@seedance.com
🔑 密码: admin123456
👤 角色: 管理员 (ADMIN)
```

### 3. 默认首页

开发模式和生产模式都默认进入 **创作页面**（对话式视频生成界面）

```
/ → /create
```


### 前端

```bash
cd client
npm run dev
```

- 端口：http://localhost:5179
- 自动登录：✅ 已启用
- 热重载：✅ 已启用

## 🔄 生产模式切换

当需要部署到生产环境时，自动登录会自动禁用：

```bash
# 构建生产版本
cd client
npm run build

# 生产版本不会自动登录，需要正常登录
```

**原理：**
```typescript
const DEV_MODE = import.meta.env.DEV // 生产环境下为 false
```

## 🔐 安全说明

### 开发环境

- ✅ 自动登录仅在开发模式启用
- ✅ 密码硬编码在客户端代码中（仅开发环境）
- ✅ 控制台会显示自动登录提示

### 生产环境

- ✅ 自动登录自动禁用
- ✅ 必须通过登录页面认证
- ✅ Token 存储在 localStorage
- ✅ 密码使用 bcrypt 加密存储

## 🐛 故障排查

### 自动登录失败

**症状：** 刷新页面后跳转到登录页

**解决：**

1. 检查后端是否运行：
   ```bash
   curl http://localhost:3000/health
   ```

2. 检查数据库连接：
   ```bash
   cd server
   npx prisma studio
   ```

3. 检查控制台错误：
   - F12 打开开发者工具
   - 查看 Console 和 Network 标签

4. 重新创建管理员账号：
   ```bash
   cd server
   npx ts-node src/scripts/update-admin.ts
   ```

### 无法访问管理员功能

**症状：** 点击"用户管理"等菜单跳转回创作页面

**原因：** 自动登录失败或权限不足

**解决：**

1. 清除浏览器缓存：
   ```
   F12 → Application → Clear storage → Clear site data
   ```

2. 刷新页面重新自动登录

3. 检查用户角色：
   ```javascript
   // 控制台执行
   console.log(JSON.parse(localStorage.getItem('user')))
   // 应该显示 role: "ADMIN"
   ```
