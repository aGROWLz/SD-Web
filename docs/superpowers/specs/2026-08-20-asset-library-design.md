# 公共素材库与中转站素材接口设计

## 目标

接入 KK 和 XKU p4 素材库上传/单素材查询接口，并将素材库配置绑定到中转站。管理员切换主中转站后，任务自动使用该中转站绑定的素材库。普通用户可以在公共素材库中查看、上传和管理素材，并在创作台右侧通过可伸缩素材栏选择素材。

## 范围

- 支持 KK 原生素材接口和 XKU p4 素材接口。
- 只实现上传、查询单个素材状态，不实现素材库全量列表同步。
- 项目本地保存原始素材和素材索引，所有已登录用户共享可见。
- 默认删除权限：素材上传者可以删除自己的素材，管理员可以删除全部素材。
- 素材库仅在 R2 可用时启用；没有 R2 时不调用素材库。

## 总体架构

`PublicAsset` 记录公共素材的元数据、项目本地文件路径和素材库 ID。文件本体保存于项目本地 `uploads/assets/shared/`，不依赖供应商列表接口。上传素材时先写入本地文件，再根据当前主中转站和 R2 配置异步注册供应商素材库；注册成功后保存 `assetId` 和状态。

任务提交时仍把本地素材引用保存到任务参数。队列处理任务时读取任务绑定的中转站：

1. R2 已配置且素材库已启用：本地文件上传到 R2，公网 URL 注册到素材库，生成请求使用 `asset://<assetId>`。
2. R2 已配置但素材库未启用或注册失败：生成请求使用 R2 公网 URL。
3. R2 未配置：图片转 Base64；音频和视频返回明确错误。

素材库注册失败不影响 R2 公网 URL 的任务降级路径，但会把素材记录标记为失败并保留错误信息，便于管理员和用户重试。

## 数据模型

在 `RelayStation` 增加 `assetLibraryConfig Json?`，保存供应商和字段映射：

```json
{
  "enabled": true,
  "provider": "KK",
  "uploadUrl": "https://ai.kkidc.com/api/v2/assets",
  "queryUrl": "https://ai.kkidc.com/api/v2/assets/{id}",
  "authHeader": "Authorization",
  "authPrefix": "",
  "fields": {
    "url": "url",
    "assetType": "asset_type",
    "name": "name",
    "projectName": ""
  },
  "projectNameValue": "default"
}
```

XKU p4 默认值为完整地址 `https://api-ai.xku.com/ark/p4/v1/assets`，字段映射为 `URL`、`AssetType`、`Name`、`ProjectName`。KK 默认字段映射为 `url`、`asset_type`、`name`。

新增 `PublicAsset`：

- `id`：项目内部 UUID。
- `ownerId`：上传用户，用于删除权限。
- `filename`、`contentType`、`bytes`、`localPath`：本地素材信息。
- `providerAssetId`：供应商素材 ID，可为空。
- `providerStatus`：`PENDING`、`ACTIVE`、`FAILED`。
- `providerUrl`、`providerError`：供应商返回的 URL 和错误信息。
- `createdAt`、`updatedAt`。

对 `ownerId`、`createdAt`、`providerStatus` 建索引。删除公共素材时同时删除本地文件和数据库记录；任务参数使用的是副本引用，删除素材不修改已提交任务。

## 后端接口

新增认证路由 `/assets`：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/assets` | 分页返回公共素材，支持 `contentType` 和关键词筛选 |
| POST | `/assets` | 接收 Data URL，保存本地文件并注册当前主站素材库 |
| GET | `/assets/:id/file` | 返回本地素材文件，用于预览 |
| POST | `/assets/:id/retry` | 重新执行 R2 + 素材库注册 |
| DELETE | `/assets/:id` | 上传者删除自己的素材，管理员删除任意素材 |

素材上传接口限制沿用本地任务素材限制：单文件不超过 30 MB，单次不超过 36 MB；只接受现有图片、音频、视频 MIME 类型。上传响应包含项目素材 ID、文件 URL、供应商素材 ID 和状态。

素材库服务负责：

- 按配置构造上传 URL、查询 URL 和请求体。
- 以中转站加密 API Key 发送 `Authorization` 请求头。
- 解析 KK 的 `data.Id`/`data.Status` 与 XKU 的大小写兼容响应。
- 供应商返回成功但缺少 ID 时视为失败。
- 查询单素材状态并更新 `PublicAsset`。

任务物化服务增加素材库回调参数：上传 R2 后，如果配置启用且该素材已有可用供应商 ID，则使用 `asset://ID`；没有 ID 或注册失败则保留 R2 URL。查询结果不会把供应商私有 URL写入用户任务参数。

## 前端交互

新增 `/assets` 页面并在侧边栏加入“素材库”：

- 使用网格展示公共素材缩略图；图片显示缩略图，视频显示首帧，音频显示音频卡片和播放控件。
- 顶部提供统一“添加素材”按钮，选择文件后上传并显示注册状态。
- 每张素材卡显示类型、大小、上传时间、素材库状态；上传者显示删除按钮，管理员对全部卡片显示删除按钮。
- 上传中、注册中、失败、重试状态均有明确反馈。

创作页右侧新增可伸缩素材栏：

- 展开时按同一公共素材列表展示小型预览，收起时只保留图标按钮。
- 点击素材卡将其加入当前创作配置框，沿用现有统一素材结构。
- 已加入的素材显示选中态，再次点击取消选择；不复制文件本体。
- 素材栏独立滚动，不改变底部配置框固定布局。
- 由于公共素材 URL 通过受保护接口返回，预览使用 `/assets/:id/file`，不直接暴露本地路径。

## 错误处理和降级

- 没有主中转站：素材仍可保存本地，但标记为“待注册”，任务提交时按 R2/Base64 规则处理。
- 没有 R2：素材库注册按钮和自动注册不可用，图片任务走 Base64，音频/视频任务在提交前阻止并提示配置 R2。
- R2 上传成功、素材库上传失败：任务使用 R2 公网 URL，素材卡显示“素材库注册失败”，支持重试。
- 供应商查询返回非 2xx、无 ID 或无效 JSON：保留错误信息，不删除本地素材。
- 删除素材时本地文件不存在仍删除数据库记录，避免脏记录阻塞用户。

## 测试范围

- 服务层：KK/XKU 字段映射、URL 模板、响应解析、状态查询、R2 降级。
- API：公共素材分页、上传大小/MIME 校验、文件权限、删除权限、重试。
- 任务处理：主站绑定素材库切换、`asset://` 优先级、R2-only 和 Base64 fallback。
- 前端：素材列表加载、上传/删除/重试、素材栏展开收起、选择素材写入配置框。
- 数据库迁移和 TypeScript 构建必须通过。
