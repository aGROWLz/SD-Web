# 中转站前缀与统一素材上传设计

## 目标

允许每个中转站自行决定是否自动补齐 `/api/v3`，并把创作台的图片、音频、视频入口合并为一个本地文件选择器。

## 中转站配置

`RelayStation` 增加 `appendApiV3` 布尔字段，默认 `true`，现有站点保持原行为。创建和编辑表单都显示“自动补齐 /api/v3”开关。开启时 URL 校验后补齐该路径；关闭时保留管理员填写的完整路径，仅移除末尾斜杠、查询参数和片段。列表接口回传该字段供编辑回显，连通测试和生成任务直接使用最终保存的 `baseUrl`。

## 素材上传

加号按钮直接打开一个支持多选的文件选择器，接受图片、音频和视频。前端根据 MIME 类型识别素材种类，必要时使用常见扩展名兜底，并继续以 Data URL 暂存在浏览器内存。用户点击生成时，现有后端流程才将本地素材上传 R2、替换成公链并提交视频请求；未配置 R2 时图片保留 Base64 回退，音频和视频返回明确错误。

## 错误处理与测试

不支持的文件格式、单文件超过 30 MB 或本地素材总量超限时不添加素材并显示错误。测试覆盖 URL 两种规范化模式、字段校验、素材类型识别、单一上传入口，以及现有 R2 图片/音频/视频转换行为。
