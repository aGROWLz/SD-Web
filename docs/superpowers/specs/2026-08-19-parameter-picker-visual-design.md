# 参数选择器视觉设计

## 目标

优化创作台的宽高比和视频时长选择交互，避免浅色选中态刺眼、原生下拉菜单窄长难用，并让时长选择能表达智能时长与两个可用区间之间的间隔。

## 设计

### 宽高比

- 点击宽高比字段后，选择面板从配置栏上方展开。
- 面板使用深色背景，宽度约 360px；桌面端为四列卡片网格，移动端为两列。
- 每张卡片显示 CSS 绘制的比例矩形示意图和比例名称。
- 当前值使用深色选中态、青绿色边框和浅色文字，禁止白色高亮。
- 选择后关闭面板，并继续写入现有 `form.ratio` 值。

### 模型与分辨率

- 模型面板使用纯圆形单选标记，只显示模型名称，不显示模型特性说明或装饰图标。
- 分辨率使用卡片选择，卡片内部只显示 `480P`、`720P`、`1080P` 或 `4K`。
- 所有弹层从对应按钮上方向上展开，水平中心与按钮中心一致，并且同一时间只允许打开一个弹层。

### 视频时长

- 使用横向滑杆替代原生下拉框。
- `-1` 代表智能时长，位于滑杆最左侧。
- `4-15` 秒为第一段连续刻度，`16-30` 秒为第二段连续刻度；两段之间保留明显的视觉间隔。
- 拖动只会落在智能、4-15、16-30 的有效值上，显示文本同步更新。
- 从 15 秒进入间隔时保持 15 秒，只有指针到达 16 秒节点才切换到 16 秒；反向拖动使用同样的严格边界。
- `16-30` 秒区间标注“2.5 专属”，标识位于 16 秒和 30 秒之间的中心。
- 继续使用现有模型能力限制，模型最大时长变化时将当前值归一化到可用范围。

### 开关与输出格式

- “音频”使用喇叭图标；开启时喇叭带声波，关闭时只显示喇叭本体。
- “AI 水印”使用星形图标；关闭时为虚线轮廓，开启时为实心星形。
- 两个开关内部只保留标准圆形滑块，不放图标。
- 输出格式使用文件图标，MP4/MOV 在向上展开的面板中选择。

## 数据与兼容性

不改变请求体字段和表单数据结构：比例仍写入 `form.ratio`，时长仍写入 `form.duration`。模型切换时复用已有 `normalizeModelSettings` 逻辑。

## 验证

- 验证各比例卡片能正确写入对应值，选中态为深色而非白色。
- 验证智能时长、4-15 秒、16-30 秒三个区段的映射和模型最大时长限制。
- 运行客户端测试与生产构建。
