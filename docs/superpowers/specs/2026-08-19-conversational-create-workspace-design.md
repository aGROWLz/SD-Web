# 对话式视频创作工作台设计

## 背景与目标

现有创作页采用分步骤表单和右侧参数检查器。页面信息分散，模式卡片与高级参数占用较多空间，创作入口缺少连续、自然的输入体验。

本次改造将创作页调整为对话式工作台。用户在同一个 Composer 中输入提示词、添加参考素材并设置常用参数，发送后创建视频任务。界面默认使用全模态参考能力，不再要求用户理解或切换底层创作模式。

## 范围

本次包含：

- 将创作页重构为消息时间线与底部 Composer。
- 默认且固定使用全模态参考请求语义。
- 将常用参数集中到 Composer 底部。
- 将所有素材入口收敛到一个 `+` 按钮。
- 移除前端的模式选择和高级参数区域。
- 保留现有任务创建、权限校验、素材校验及错误处理。

本次不包含：

- 新增聊天会话、消息记录或上下文继承的后端模型。
- 修改管理员中转站、用户生成权限和任务队列。
- 删除后端对高级参数的兼容能力。
- 在浏览器内直接上传本地视频文件；视频仍使用 HTTP(S) URL 或 `asset://` 素材 ID。

## 交互结构

### 页面主体

创作页使用单列布局，不再显示右侧参数面板。页面由以下区域组成：

1. 顶部轻量标题栏：显示页面标题、系统状态和权限提示。
2. 中部消息时间线：显示当前页面会话内已提交的创作请求和任务提交结果。
3. 底部 Composer：承载素材、提示词、参数与生成按钮。

消息时间线只承担界面反馈，不改变任务模型。每次点击生成仍创建一个独立任务；刷新页面后不恢复本地会话，也不把上一条消息自动拼接进下一次请求。

### Composer

Composer 为页面最主要的操作区域，参考用户提供图片中的一体化输入框：

- 上部为已添加素材的预览列表或缩略图。
- 中部为多行提示词输入框。
- 左下角为唯一的 `+` 素材按钮。
- 下部为紧凑参数栏。
- 右下角为生成按钮。

`+` 按钮打开素材菜单，提供以下操作：

- 添加图片：打开本地图片选择器。
- 添加音频：打开本地音频选择器。
- 添加视频：打开输入 HTTP(S) URL 或 `asset://` 素材 ID 的对话框。

添加成功后，素材显示在 Composer 内部。用户可以查看素材类型、名称和引用角色，也可以单独删除。素材统一使用 `reference_image`、`reference_video` 和 `reference_audio` 角色。

### 参数栏

参数栏只显示以下 7 项：

| 界面项 | API 字段 | 交互形式 |
| --- | --- | --- |
| 模型 | `model` | 下拉菜单 |
| 分辨率 | `resolution` | 紧凑下拉菜单 |
| 宽高比 | `ratio` | 紧凑下拉菜单 |
| 视频时长 | `duration` | 紧凑下拉菜单 |
| 生成声音 | `generate_audio` | 开关菜单项 |
| AI 水印 | `watermark` | 开关菜单项 |
| 输出格式 | `output_format` | MP4 / MOV 选项 |

参数控件在桌面端横向排列，空间不足时自然换行。移动端必须换行显示，不能产生横向滚动。声音、水印和输出格式可合并到一个紧凑的“输出设置”菜单中，但用户不需要离开 Composer。

模型变化后继续执行现有联动规则：

- 不支持的分辨率自动回退到该模型可用值。
- Seedance 2.5 以外的模型不能选择 MOV。
- 超过模型上限的时长回退为智能时长。

`omni_reference_task_type` 不作为用户参数展示，前端固定提交 `auto`。模型根据素材和提示词判断参考生成、视频编辑或视频延长任务。

## 默认状态与请求语义

前端表单默认状态使用 `reference` 模式。页面不显示模式选择器，也不允许切换到文生视频、首帧、首尾帧或样片任务。

全模态参考允许以下输入组合：

- 只有提示词。
- 只有参考素材。
- 提示词与图片、视频、音频的任意有效组合。

提交时至少需要提示词或一项素材，不能发送空请求。Seedance 2.0 系列不能只提交音频；此限制继续在提交前校验。请求中的常用参数严格使用 `SEEDANCE API.md` 定义的字段和取值。

高级参数不再进入此创作页的前端状态，也不由该页面提交，包括：

- `priority`
- `execution_expires_after`
- `callback_url`
- `safety_identifier`
- `return_last_frame`
- `tools.web_search`

后端继续兼容这些字段，避免影响其他调用方。

## 消息与状态反馈

页面初始显示简短的助手欢迎消息，不使用大段功能说明。

发送时：

1. 校验权限、提示词、素材和模型约束。
2. 将提示词、素材摘要和参数摘要加入消息时间线。
3. 锁定当前发送按钮并显示提交状态。
4. 调用现有任务创建接口。
5. 成功后显示任务已进入队列，并清空提示词和素材；常用参数保留，方便连续创作。
6. 失败时在 Composer 附近显示错误，保留全部输入，便于修改后重试。

用户没有生成权限时，Composer 仍可查看，但生成按钮禁用，并在页面顶部保留现有权限提示。

## 视觉规范

- 延续项目现有深色与薄荷绿视觉语言，不引入新的主色体系。
- Composer 是单一、完整的工作区域，不在其中嵌套装饰性卡片。
- 参数使用图标、下拉菜单、开关和分段选项，避免大块文字按钮。
- 素材预览与消息内容保持清晰层级，不与参数栏争夺空间。
- 生成按钮使用熟悉的发送图标，并提供悬停提示。
- 桌面端控制整体内容宽度；移动端使用全宽布局并留出安全边距。
- 页面不得出现横向溢出、文本遮挡或动态内容导致的明显布局跳动。

## 组件边界

为避免继续扩大 `Create.vue` 的职责，页面拆分为以下局部组件：

- `ConversationTimeline`：渲染欢迎消息、本地用户消息和任务提交结果。
- `CreateComposer`：组织素材预览、提示词、参数栏和发送操作。
- `MaterialMenu`：管理唯一的 `+` 入口及素材选择动作。
- `ParameterBar`：渲染 7 项常用参数及模型联动状态。

`Create.vue` 负责权限、表单状态、请求提交和组件编排。Seedance 字段定义、默认值、请求构造和纯校验继续集中在 `features/create/seedance.ts`。

## 错误处理

- 空请求：提示至少输入提示词或添加一项参考素材。
- 素材过大：沿用本地素材总大小限制，不清空已输入内容。
- 视频来源无效：只接受 HTTP(S) URL 或 `asset://` 素材 ID。
- 模型与素材不兼容：提交前给出明确的中文错误信息。
- 请求失败：保留 Composer 状态，并在输入区域附近显示服务端错误。
- 重复提交：任务创建期间禁用生成按钮。

## 测试与验收

单元测试覆盖：

- 默认模式为 `reference`。
- 提示词或素材任一存在即可构造请求，空请求被拦截。
- 全模态素材使用正确的 `reference_*` 角色。
- 请求仅包含 7 项可见参数及固定的 `omni_reference_task_type=auto`。
- 高级参数不再由创作页请求构造器提交。
- 模型、分辨率、时长和输出格式联动保持正确。

组件与浏览器验收覆盖：

- 页面无模式选择器、右侧参数栏和高级参数区域。
- `+` 按钮可以进入所有支持的素材操作。
- 成功提交后消息进入时间线，参数保留，提示词和素材清空。
- 提交失败后用户输入不丢失。
- 桌面与移动端参数栏均完整可用，无横向溢出。
- 登录用户与无生成权限用户的状态正确。

## 完成标准

- 创作页第一视觉焦点为对话式 Composer。
- 所有常用参数都在 Composer 底部完成设置。
- 素材入口只有一个 `+` 按钮。
- 默认使用全模态参考，页面不再暴露模式概念。
- 前端不展示或提交高级参数。
- 现有任务创建、管理员配置和用户权限功能不回归。
- 前端测试、项目测试、生产构建及桌面和移动端浏览器检查全部通过。
