# 中转站模型重定向设计

## 目标

每个中转站可分别为 SeeDance 2 的四个标准模型配置外发别名。留空时发送标准模型名；配置后仅修改发往该中转站的请求体 `model`，不修改任务数据库中的标准配置。

## 模型

- `doubao-seedance-2-5`（平台默认）
- `doubao-seedance-2-0`
- `doubao-seedance-2-0-fast`
- `doubao-seedance-2-0-mini`

## 数据与接口

`RelayStation` 使用可空 JSON 字段 `modelRedirects` 保存以标准模型名为键、以中转站模型名为值的映射。创建、编辑和列表接口均返回规范化映射；空白值被移除，未配置时返回空对象。别名必须是最多 100 个字符且不含控制字符的字符串。

## 请求流程

任务继续保存平台标准模型名。队列处理器读取任务与中转站后，克隆任务参数并按中转站映射替换 `model`，然后提交到 SeeDance API。该转换不修改原始任务参数。

## 管理界面

添加和编辑中转站弹窗增加“模型重定向”区块，四个输入框纵向排列。每项标注标准模型名，留空表示直接使用该名称。保存、编辑回填和启停操作都保留完整映射。

## 验证

单元测试覆盖别名替换、空白回退、不修改原对象、映射清理及非法值；接口测试覆盖保存和序列化；前端结构测试覆盖四个输入框及请求载荷。最后运行前后端全量测试和构建，并在浏览器检查添加/编辑弹窗。
