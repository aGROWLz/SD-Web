# 对话式视频生成界面使用指南

## 🎨 新功能亮点

我已经为你创建了一个全新的**对话式视频生成界面**，模仿了你提供的截图风格！

## 🚀 如何使用

### 1. 访问创作页面

登录后，点击左侧菜单的 **"创作"** 按钮（魔法棒图标），即可进入对话式生成界面。

### 2. 开始对话

在底部输入框中描述你想要的视频，例如：

```
一只橘猫在阳光下打盹，温馨治愈的画面
```

按 **Enter** 发送，AI 会回复并展示参数配置卡片。

### 3. 调整参数

在参数卡片中，你可以调整：

- **模型**: Seedance 2.5 / 2.0 / 2.0 Fast / 2.0 Mini
- **分辨率**: 1080p / 720p / 480p
- **时长**: 自动 / 5秒 / 10秒 / 15秒
- **宽高比**: 16:9 / 9:16 / 1:1 / 自适应

### 4. 确认生成

点击 **"确认生成"** 按钮，系统会：

1. 创建视频生成任务
2. 显示进度卡片（带加载动画）
3. 实时更新进度条
4. 完成后自动显示视频

### 5. 查看结果

视频生成完成后，你可以：

- 🎬 **直接播放** - 在对话框中预览视频
- 📥 **下载视频** - 点击下载按钮保存到本地
- 🔄 **重新生成** - 使用相同提示词重新生成

## 🎯 快捷操作

### 使用示例模板

右侧边栏有推荐的热门模板：

- **流浪式环片** - 科幻风格，宇宙场景
- **摇摆老鼠** - SD 2.5
- **治愈动画** - SD 2.5
- **抖音短视频** - 竖屏 9:16

点击任一模板即可自动填充提示词。

### 上传参考素材

点击输入框左侧的 **"+"** 按钮，可以上传：

- 图片（用作首帧或尾帧参考）
- 视频（用作风格参考）

### 查看历史记录

点击底部的 **"历史记录"** 按钮，可以查看之前的对话和生成的视频。

## 💡 提示词技巧

### 好的提示词示例

```
一只金色的拉布拉多犬在海边奔跑，夕阳西下，温暖的色调
```

```
赛博朋克风格的城市夜景，霓虹灯闪烁，未来感十足
```

```
一朵玫瑰花缓缓绽放，微距拍摄，柔和的光线
```

### 提示词要素

1. **主体**: 描述主要内容（人物/动物/物体）
2. **动作**: 说明在做什么
3. **场景**: 背景环境
4. **风格**: 艺术风格或氛围
5. **细节**: 光线、色调、镜头等

## 🔧 键盘快捷键

- **Enter** - 发送消息
- **Shift + Enter** - 换行
- **Ctrl + K** - 清空输入框
- **↑** - 重新编辑上一条消息

## 📱 响应式设计

- **大屏幕** (> 1200px) - 显示右侧示例栏
- **中屏幕** (≤ 1200px) - 隐藏右侧栏，全宽对话
- **小屏幕** - 自适应移动端布局
